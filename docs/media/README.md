# Demo media

`snapmark-demo.gif` and `snapmark-demo.mp4` show the real SnapMark editor adding an arrow, rectangle, and text, then pixelating, cropping, and copying the result.

The recording runs SnapMark with `SNAPMARK_DEMO=1`. That mode loads the image generated by `DemoImageFactory` instead of a screenshot. The recording targets the SnapMark window, not the desktop. It contains no real account, filename, message, browser tab, or desktop capture.

The README embeds the GIF. Clicking it opens the smaller, higher-frame-rate MP4.
